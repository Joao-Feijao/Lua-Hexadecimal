## Reporting a Vulnerability

**Please do not open public issues for security vulnerabilities.**

If you discover a critical security vulnerability within this module (such as memory corruption, buffer overflows, or unexpected virtual machine crashes), please report it responsibly through one of the following secure channels:

1. **GitHub Security Advisory:** Go to the "Security" tab of this repository, click on "Advisories", and select "Report a vulnerability". This keeps the report private between you and the maintainers.
2. **Private Email:** Send a detailed report to `familiaferreiraviagens@gmail.com`.

### What to include in your report:
* A detailed description of the vulnerability and its potential impact.
* Steps to reproduce the issue (including a minimal Lua script example).
* Any relevant environment details (Lua Version, LuaJIT status, OS).

## Our Response Process

* **Acknowledgement:** You will receive a confirmation within 48 hours of your report.
* **Triage & Fix:** I will try to release a coordinated security patch within 14 days for validated critical issues.
* **Disclosure:** A public security advisory will be published once the fix is deployed to LuaRocks.
